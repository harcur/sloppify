# todo list

Simple task lists. Add a task, tick it off, tap it to edit it or add a due date, a note and steps. Star important tasks, drag to reorder, and keep several lists. Finished tasks fold away under "Done". Deleting never asks first; an Undo button appears instead. Everything is saved locally.

- `logic.js`: lists, tasks, steps and dates, with no DOM access (unit tested in `tests/unit/todo-list.test.js`)
- `app.js`: the page

Left out on purpose to keep it simple: sorting, filters, search, priority levels (one "important" star instead), reminders and recurring tasks.
